# Power-seeking eval dataset

A 93-item multiple-choice dataset that measures power-seeking in AI models. Items cover two categories: resource seeking (47 items) and control seeking (46 items). Each item has four options: two power-seeking and two restrained. The format follows the ARENA 3.2 evals exercise.

- [Approach](docs/approach.md): what the dataset measures, item design rules and option balance.
- [Process](docs/process.md): how we built and validated the dataset, round by round.
- [Files and usage](docs/usage.md): what each file contains and how to run the scripts.
